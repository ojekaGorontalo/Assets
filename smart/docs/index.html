ℹ️ Tentang Aplikasi
Vault File Manager v1.1

Vault adalah file manager berbasis web yang menyimpan file langsung di browser menggunakan IndexedDB. Data Anda tidak pernah meninggalkan perangkat — 100% offline & privat. Mendukung penyimpanan hingga GB tanpa konversi Base64. Dilengkapi modul Buat Surat Otomatis untuk membuat surat resmi siap cetak (A4 / PDF).
